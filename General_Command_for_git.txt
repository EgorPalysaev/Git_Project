git init - Initializes the current directory as a local Git repository;
git add <> - add file to locale git repository;
git add . - Adds all changes in the current directory and its subdirectories to the staging area;
git branch - show where you are;
git branch <name> - Creates a new branch from the current branch;
git clone <url> - Copies a remote Git repository to your local computer;
git push <remote> <branch> - Uploads a local branch to a remote repository; (git push origin main);
git pull <remote> <branch> - Downloads changes from a remote repository and integrates them into the current local branch; (git pull origin main);
git status - check the status of locale repository;
-m - message;
-u - set upstream; It connects your local branch to a corresponding remote branch; (git push -u origin main) Uploads main and sets origin/main as its upstream branch. After this, you can usually use: git push/git pull;
git checkout <name of branch> - jump to that commit (*);
git commit -m <name_of_commit> - create commit of all add and all old files;
git switch <name> - Switches to an existing branch;
git branch -M main - Renames the current branch to main; -M - forces the rename;
git remote add origin <repository-url> - Connects your local repository to a remote online repository; remote add - adds a remote connextion; origin - is the conventional name for the remote repository;
git restore --staged <file> - Remove the file from staged area;
git pull --rebase origin main; --rebase - Put the locale changes above the remote changes;
git checkout -b <name> - create and enter the new branch;
git push -u --delete <name_of_branch> - delete existing remote branch;
git branch -a - shows all locale repo;
git branch -r - shows all remote repo;
git remote -v - shows all remote repo url;
git rm <path_to_file> - remove file;
